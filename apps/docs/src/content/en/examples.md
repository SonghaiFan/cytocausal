# Independent examples

Each example isolates one task and includes a live interface, complete component source and the same fictional garden dataset. No participant data is used.

| Task | Example |
| --- | --- |
| Render a complete interface | [Workspace](/en/example-workspace/) |
| Assemble a graph and sidebar | [Composition](/en/example-compose/) |
| Compare a rename across snapshots | [Versions](/en/example-versions/) |
| Call path and loop APIs directly | [Analysis](/en/example-analysis/) |

The source files in `apps/docs/src/components/examples/` are compiled by the docs site. Packages are still workspace packages: run `npm run dev:docs` in this repository, or copy an example together with `data.ts` and `garden.json` into the starter. No additional example dependencies are needed.
