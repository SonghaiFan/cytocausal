## Run in your project

Put the files in the repository starter’s `src/examples/`, then import the component from `src/components/App.tsx` and return `<Example />`. Keep the starter’s existing client-only loading boundary. Give graph containers a height, for example `height: 560px`; stack graph and sidebar at narrow widths.

These examples cover viewing and analysis, not graph editing, persistence or collaborative synchronisation.
