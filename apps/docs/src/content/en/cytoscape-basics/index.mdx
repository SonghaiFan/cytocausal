# Cytoscape.js

Learn graph data, layouts, styles, events and algorithms in Cytoscape.js. Each chapter links to standalone vanilla JavaScript and React demos, with Preview and Code views.

No prior Cytocausal knowledge is required. Follow the seven chapters in order, or open the topic you need.

| Chapter | What you will learn |
| --- | --- |
| [1. Setup & initialization](/en/cytoscape-basics/setup/) | Create an instance, size its container and configure it |
| [2. Nodes & edges](/en/cytoscape-basics/elements/) | Add, update, select and traverse elements |
| [3. Layouts & viewport](/en/cytoscape-basics/layouts/) | Choose layouts, zoom and pan |
| [4. Styles & animation](/en/cytoscape-basics/styles/) | Apply selectors, style rules and animation |
| [5. Interactions & events](/en/cytoscape-basics/events/) | Handle taps, dragging and event cleanup |
| [6. Graph algorithms](/en/cytoscape-basics/algorithms/) | Explore paths, centrality and connectivity |
| [7. Import & export](/en/cytoscape-basics/data/) | Read data and export JSON, CSV and images |

## Use with Cytocausal

When extending the causal graph components, read [Extend with Cytoscape.js](/en/cytoscape-integration/) for dataset, style and interaction integration.
