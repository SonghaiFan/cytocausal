# cytocausal

A React web app starter for causal graphs, built on Next.js. Clone it, swap in your data, and build your own interface.

It gives you:

- one data model for causal graphs and their versions
- graph views with stable layouts and animated version changes
- feedback loop detection and directed centrality
- two complete example apps to learn from

Start with [Getting started](/en/getting-started/).

## Example apps

- [Perspectiva](/en/case-perspectiva/) compares versions of causal loop diagrams.
- [Causal Explorer](/en/case-explorer/) explores a large causal network of everyday events.
