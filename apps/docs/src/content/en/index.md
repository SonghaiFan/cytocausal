# cytocausal

A toolkit for building causal graph interfaces that can be traced and compared, for research on participatory modelling and causal extraction from text. It's a Next.js and React starter: clone it, swap in your data, and build your own interface.

It gives you:

- **provenance** on every node and link: who stated it, and on what grounds, with agreement shown when several people's graphs are combined. See [Provenance and agreement](/en/provenance/)
- **comparison** of versions node by node, even through renames, merges and splits, with stable layouts and animated changes
- **causal analysis**: feedback loops marked reinforcing or balancing, causal paths and directed centrality
- two complete example apps from real research to learn from

Start with [Getting started](/en/getting-started/).

## Example apps

- [Perspectiva](/en/case-perspectiva/) compares versions of causal loop diagrams.
- [Causal Explorer](/en/case-explorer/) explores a large causal network of everyday events.
