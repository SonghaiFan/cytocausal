# cytocausal

用来构建可追溯、可比较的因果图界面的工具包，面向参与式建模和文本因果抽取的研究。它基于 Next.js 和 React，克隆后换上你的数据，就能开发自己的界面。

它提供：

- **出处**：每个节点和连线都记录了提出者和依据；合并多人的图时还会显示共识程度。详见[出处与共识](/zh-cn/provenance/)
- **比较**：逐个节点匹配不同版本，即使经过改名、合并或拆分也能对上，布局稳定，变化带动画
- **因果分析**：区分增强回路和平衡回路的反馈回路检测、因果路径和有向中心性
- 两个来自真实研究的完整示例应用

请从[快速开始](/zh-cn/getting-started/)入手。

## 示例应用

- [Perspectiva](/zh-cn/case-perspectiva/)：比较不同版本的因果回路图。
- [Causal Explorer](/zh-cn/case-explorer/)：探索日常事件的大型因果网络。
