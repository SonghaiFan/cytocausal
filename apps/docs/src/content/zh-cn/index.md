# cytocausal

基于 Next.js 的因果图 React Web 应用 starter。克隆后换上你的数据，就能开发自己的界面。

它提供：

- 适用于因果图及其版本的统一数据模型
- 布局稳定、版本切换带动画的图视图
- 反馈回路检测和有向中心性分析
- 两个可供参考的完整示例应用

请从[快速开始](/zh-cn/getting-started/)入手。

## 示例应用

- [Perspectiva](/zh-cn/case-perspectiva/)：比较不同版本的因果回路图。
- [Causal Explorer](/zh-cn/case-explorer/)：探索日常事件的大型因果网络。
