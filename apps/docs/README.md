# cytocausal docs

Homepage, live showcase and guides for the cytocausal causal graph library, in English and Chinese, built with [Nextra](https://nextra.site) on Next.js.

From the repository root:

```sh
npm run dev:docs
```

Search is generated by the build, so it only works after `npm run build -w @cytocausal/docs`.

## Project structure

- `src/content/en/`, `src/content/zh-cn/`: the guides, with sidebar order in each `_meta.ts`.
- `src/app/`: routes for the guides.
- Language-prefixed links are generated by Nextra; no proxy is needed.
- `e2e/`: browser tests, run with `npm run test:e2e -w @cytocausal/docs` after a build.

The site uses static export. Set `NEXT_PUBLIC_BASE_PATH=/cytocausal` for GitHub Pages. `npm run start -w @cytocausal/docs` serves the exported `out/` directory; use the same base-path environment variable when previewing that build.

The homepage lives in `src/components/Home.tsx`, with language entry points in `src/content/*/index.mdx`. It introduces the library, links to the showcase and case studies, and distinguishes the available starter from the browser-local Studio application.

## Examples and reference

Runnable examples live in `src/components/examples/`. After editing their source, run `node scripts/sync-examples.mjs --write` to refresh the source displayed in the docs. `npm run check:examples` checks for drift; `npm run test:examples` checks the importer and documented graph results. The docs typecheck compiles all four example components.

Navigation groups preserve existing guide URLs. `import-data.mdx` is the end-to-end data tutorial; `api-core.md`, `api-react.md` and `api-cytoscape.md` document the primary integration surface. `brand.md` describes the yellow causal sunburst and links to the SVG assets.
