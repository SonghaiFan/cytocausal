# cytocausal docs

Guides for building on cytocausal, in English and Chinese, built with [Nextra](https://nextra.site) on Next.js.

From the repository root:

```sh
npm run dev:docs
```

Search is generated by the build, so it only works after `npm run build -w @cytocausal/docs`.

## Project structure

- `src/content/en/`, `src/content/zh-cn/`: the guides, with sidebar order in each `_meta.ts`.
- `src/app/`: routes for the guides.
- `src/proxy.ts`: adds the language to page routes, which have none of their own.
- `e2e/`: browser tests, run with `npm run test:e2e -w @cytocausal/docs` after a build.

The language proxy needs a server, so this site doesn't use static export.
