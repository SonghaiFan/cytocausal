# cytocausal docs

Cytoscape.js tutorials in English and Chinese, with React playgrounds and vanilla JavaScript demos. Built with [Nextra](https://nextra.site) on Next.js.

Run the scripts from the repository root, using Node.js 22.12 or later:

```sh
npm run dev
npm run typecheck
npm run check:content
npm run build
npm run start
```

Search is generated by the build, so it only works after `npm run build`.

## Project structure

- `src/content/en/`, `src/content/zh-cn/`: the tutorials, with sidebar order in each `_meta.ts`.
- `src/examples/`: the React playgrounds and layout configurations.
- `src/components/`: the site shell, demo pages and graph components.
- `src/app/`: routes for guides (`/en/styles/`), React playgrounds (`/examples/react/styles/`) and vanilla demos (`/examples/vanilla/en/styles/`).
- `public/demos/vanilla/`: standalone HTML demos, which load their libraries from CDNs.
- `src/lib/chapters.ts`: chapter metadata.
- `src/lib/legacy-redirects.json`: old URLs, applied in `next.config.mjs`.

The React playground text is in Chinese, so those pages use the Chinese sidebar.

Redirects and search need a server build, so this site doesn't use static export.
