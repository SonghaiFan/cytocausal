cytocausal / causal graph library

让因果图成为可以探索的界面。

基于 Cytoscape.js，为因果图提供专门的交互、可组合的 React 组件与分析 API。从证据到反馈回路，从一个版本到另一个版本。

体验 Showcase →从 Starter 开始 →

先试一张小图

虚构的咖啡店模型 · 可直接操作

点击节点探索原因与结果；切换 V1 / final 查看变化；选择反馈回路查看它经过的节点。示例图中的标签为英文。

Library

围绕因果关系设计的交互与 API。

在 Cytoscape.js 渲染之上，加入因果语义、证据追溯、版本对应与交互组件，作为应用共享的基础。

查看组件与接入方式 →
追溯每个关系的依据 →
保留节点和连线的出处与贡献者，查看多人模型中的共识与分歧。
看清版本之间的变化 →
用明确的节点对应关系处理改名、合并与拆分，让布局帮助读者跟随变化。
探索路径与反馈回路 →
沿原因与结果探索，查找有向路径，并在极性信息完整时区分增强与平衡回路。

同一个 Library，两条应用路径

Studio · 在线绘图

在浏览器中创作因果图

在浏览器中添加节点与连线、编辑名称和极性，再切换到探索模式。自动保存在当前浏览器，支持 JSON 导入导出。
