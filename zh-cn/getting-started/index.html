快速开始

快速开始

cytocausal 是基于 Cytoscape.js 的因果图 library。当前可以通过 React / Next.js starter 构建自己的应用。各 package 仍为工作区内的私有包；npm 发布属于后续规划。Studio 是独立的浏览器本地绘图应用。

需要 Node.js 22.18 或更高版本。

git clone https://github.com/SonghaiFan/cytocausal.git
cd cytocausal
npm install
npm run dev

打开 http://localhost:3102，可以看到一个虚构的咖啡店小模型，它有两个版本，并列出了反馈回路。

可选基础知识：Cytoscape.js 基础与扩展使用同一张小因果图对照原生 Cytoscape.js 和 cytocausal，适合需要自定义样式或交互时阅读。

改成你自己的应用

需要修改的内容都在 apps/starter/src 中：

文件作用
data.ts你的图，从替换这个文件开始
components/App.tsx页面，只有一个 CausalWorkspace

如果想保留 starter 作为参考，请把 apps/starter 复制为 apps/your-app，并修改其 package.json 中的 name。

添加数据

要进一步定制，请参阅组件和主题与样式。

数据需要符合数据模型。只有 ID 和标签是必需的，所以一张图可以很简单：

import type { CausalDataset } from "@cytocausal/core";
 
export const dataset: CausalDataset = {
  id: "my-graph",
  snapshots: [
    {
      id: "final",
      nodes: [
        { id: "rain", label: "Rain" },
        { id: "floods", label: "Floods" },
      ],
      edges: [{ id: "rain-floods", source: "rain", target: "floods", polarity: "positive" }],
    },
  ],
};

validateDataset 发现的问题会显示在 starter 侧边栏顶部。

仓库结构

路径内容
apps/starter用于开发的起点应用
apps/perspectiva示例：并排比较版本
apps/explorer示例：探索大型网络
apps/docs本站
packages/core数据模型、验证和分析
packages/cytoscape主题、样式、布局、过渡和高亮
packages/reactCausalWorkspace、各组件和 useCausalGraph

运行示例：npm run dev:perspectiva 和 npm run dev:explorer。
