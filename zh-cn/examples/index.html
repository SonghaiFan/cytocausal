独立示例

每个示例只演示一项任务，包含可操作界面、完整组件源码和同一份虚构花园数据。示例标签为英文，数据不来自研究参与者。

任务示例
用数据启动完整界面Workspace
自行组合图与侧栏Composition
比较节点改名后的版本Versions
直接调用路径和回路 APIAnalysis

这些源码位于 apps/docs/src/components/examples/，直接被站点编译，而不是伪代码。当前 package 仍是工作区包：运行仓库中的 npm run dev:docs，或把示例及 data.ts、garden.json 复制到 starter 中使用。无需额外安装示例依赖。
