# @cytocausal/core

Renderer-independent causal graph data, evidence, validation, versions, directed paths and feedback loops. No runtime dependencies.

Part of [cytocausal](https://github.com/SonghaiFan/cytocausal), a React library built on Cytoscape.js. For graph interfaces, start with @cytocausal/react.

This alpha uses ESM and requires a modern JavaScript runtime. It analyses supplied relationships; it does not infer or establish causality.
