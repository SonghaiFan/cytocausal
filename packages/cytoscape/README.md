# @cytocausal/cytoscape

Causal graph styles, layouts, highlighting and transitions for Cytoscape.js.

Uses your Cytoscape installation as a peer dependency. This alpha is tested with Cytoscape.js 3.31.0. Importing this package currently registers cola, dagre and fcose on that Cytoscape module. It provides integration functions, not a cytoscape.use() plugin.

For the complete React exploration and authoring interface, use @cytocausal/react. Ships ESM JavaScript and TypeScript declarations.
