Getting started

Getting started

cytocausal is a causal graph library built on Cytoscape.js. The React / Next.js starter is the current way to build your own application with it. Packages are private workspace packages; an npm release is planned. Studio is a separate browser-local drawing app.

You need Node.js 22.18 or later.

git clone https://github.com/SonghaiFan/cytocausal.git
cd cytocausal
npm install
npm run dev

Open http://localhost:3102. You’ll see a small made-up model of a coffee shop, with two versions and its feedback loops listed.

Optional background: Cytoscape.js basics and extensions compares native Cytoscape.js and cytocausal using the same small causal graph. Read it when you want to customise styles or interactions.

Make it yours

Everything you need to change is in apps/starter/src:

FileWhat it does
data.tsYour graph. Start by replacing this
components/App.tsxThe page, which is one CausalWorkspace

To keep the starter as a reference, copy apps/starter to apps/your-app and change name in its package.json.

Add your data

To go further, see Components and Themes and styles.

Your data needs to fit the data model. Only ids and labels are required, so a graph can be as simple as:

import type { CausalDataset } from "@cytocausal/core";
 
export const dataset: CausalDataset = {
  id: "my-graph",
  snapshots: [
    {
      id: "final",
      nodes: [
        { id: "rain", label: "Rain" },
        { id: "floods", label: "Floods" },
      ],
      edges: [{ id: "rain-floods", source: "rain", target: "floods", polarity: "positive" }],
    },
  ],
};

The starter shows any problems validateDataset finds at the top of the sidebar.

What’s in the repo

PathContents
apps/starterThe app to build from
apps/perspectivaExample: comparing versions side by side
apps/explorerExample: exploring a large network
apps/docsThis site
packages/coreData model, validation and analysis
packages/cytoscapeThemes, styles, layouts, transitions and highlighting
packages/reactCausalWorkspace, its components and useCausalGraph

Run the examples with npm run dev:perspectiva and npm run dev:explorer.
