Causal Explorer

Case study: Causal Explorer

Open the app ↗

Causal Explorer shows the causal graph from the ACCESS benchmark, which covers abstract events in everyday life. Generalised event descriptions from the GLUCOSE dataset were clustered into abstract events, and annotators judged the causal links between them. The question is how events connect at scale.

ItemDetails
DataOne network, in one snapshot
Size725 nodes and 1,494 edges
LinksDirected, without polarity
Evidence4,708 generalised event descriptions
PositionsPrecomputed for the full benchmark, with force and centrality layouts worked out in the browser

The figures above describe the full benchmark. The public demo shows a sample of its 100 most central events, and the full benchmark is available on request .

What it needed

  • Finding events by what they mean, not just by name
  • Reading the sentences behind a node
  • Seeing what causes a node and what it leads to
  • A readable view of a dense graph

What was wrong

The original app ran on Sigma, and its data was sound. The problems were in exploring it:

  • Search only matched the start of a label, and 716 of 725 labels start with “a person”. Searching for sleep found nothing.
  • Sentences appeared in a hover card that vanished when the mouse moved away.
  • Highlighting didn’t separate causes from effects.
  • Node sizes ignored direction.
  • Every node was its own cluster, so the filters added up to 1,450 checkboxes that couldn’t group anything.

Moving to Cytoscape

The move depended on one question: could Cytoscape draw this graph with labels? Benchmarks showed 60 fps, so both demos could share one engine.

The harder problem was keeping labels readable, which took collision handling.

Result

Search now finds words anywhere in labels and sentences. Clicking a node keeps its sentences, causes and effects in a side panel, and a second click compares two nodes. The analysis of the full graph also found something new: 213 of the 725 nodes form a single set of feedback loops, so the network isn’t a simple chain of causes.

The sample keeps positions worked out for all 725 nodes, so it has gaps where the others were. A force layout for the 100 nodes shown takes about 0.2 s, so the app offers one, along with rings by centrality. With a computed layout, showing only feedback loops lays out the loops on their own. Zooming spreads nodes apart while every mark keeps its size, and a switch compares this with the other zoom modes.

Publication

The graph comes from ACCESS: A Benchmark for Abstract Causal Event Discovery and Reasoning  (NAACL 2025), which is built on GLUCOSE . GLUCOSE’s license limits this data to non-commercial use.

Run it

npm install
npm run dev:explorer

Open http://localhost:3101.

Set NEXT_PUBLIC_PERSPECTIVA_URL and NEXT_PUBLIC_EXPLORER_URL when building the docs to point the Open the app buttons at deployed apps. Without them, the buttons open the local servers, so start the app first.
