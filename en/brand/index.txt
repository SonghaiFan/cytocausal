# Visual identity

![cytocausal: the yellow causal sunburst](/brand/identity.svg)

## The visual hammer: a yellow causal sunburst

A yellow focus node, stepped sunburst sectors and directed graph paths. The sectors echo the radial exploration interaction: start at a node, follow a direction and reach the next layer. Repeat this silhouette across the site, app entry and repository artwork.

**Verbal companion:** Follow a cause. Explore outward.

The mark expresses directed relationships and progressive exploration; it is not a promise that every dataset contains a loop or that the library proves causation.

## Logo assets

- [Primary mark — SVG](/brand/mark.svg): navigation, favicon, repository avatar and small application marks.
- [Wordmark — SVG](/brand/wordmark.svg): presentations and light-background headers. The editable wordmark uses Arial/Helvetica fallbacks; outline its text before print production if exact typography is needed.
- [Monochrome mark — SVG](/brand/mark-mono.svg): one-colour printing, with the yellow field omitted.
- [Identity board — SVG](/brand/identity.svg): project introduction and presentation reference.

The primary mark is the canonical 64 × 64 vector. Use at 24 px or larger in interfaces; 16 px is reserved for the favicon. Leave at least 8/64 of its width as clear space. Keep the arrow, node positions and proportions unchanged. Do not stretch, add shadows, rotate or replace the yellow with unrelated accents.

## Palette and type

| Token | Value | Use |
| --- | --- | --- |
| Yellow | `#F4CD3C` | Logo field, primary action, restrained brand accents |
| Ink | `#20201C` | Mark, text on yellow, primary text |
| Paper | `#F7F6F0` | Optional presentation background |
| Dark text accent | `#53420B` | Readable brand links on a light background |

Use ink text on yellow; never white text on yellow. In dark mode keep the yellow mark and use yellow as a text accent. Use the site's existing sans-serif stack and a lowercase `cytocausal` wordmark. Code remains monospace.

## Repeat the shape, not just the colour

Use one yellow sunburst at the start of a page or in its navigation. Pair it with a short statement about the task, then let the real graph provide the detail. Repository artwork and presentation covers can enlarge the same mark against a solid yellow field. Avoid decorative networks, generic gradients and multiple competing logo variants.

The application graph keeps its semantic palette: causes, effects, selection, polarity and changes must remain distinguishable. Brand yellow does not replace all those colours. Interaction rule: select a yellow focus node, reveal sectors, preview a direction on hover, then move focus on activation. Use the library’s real radial menu for this behaviour rather than a decorative spinner. The mark has no automatic animation; motion in the product should explain actual graph changes, with reduced-motion behaviour respected.
